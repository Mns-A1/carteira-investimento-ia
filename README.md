# Carteira de Investimento com Consultoria Assistida por IA

Sistema de gestão de carteira de investimentos com dois perfis de usuário — **Investidor** e **Consultor**. O Investidor registra e acompanha seus investimentos (Tesouro Direto, CDB/CDI, Ações, Poupança). O Consultor acompanha as carteiras de seus clientes e propõe rebalanceamentos, com apoio de uma análise de IA que gera dados estruturados (score de risco, alertas de concentração, sugestões) — a decisão final de aplicar qualquer mudança é sempre do Investidor.
